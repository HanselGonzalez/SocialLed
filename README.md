# 💡 Solky - Digital LED Sign App

Solky is a versatile mobile application designed to create modern, highly customizable digital LED signs. It allows you to design, preview, and display messages in full screen, with the ability to instantly save your favorite creations for future use.

## 🚀 Main Features

* **Custom Text & Positioning:** Write any message and move the text freely across the screen to fit your needs perfectly.
* **Full Customization:** Apply vibrant colors to both the text and the background, and choose from multiple available background designs.
* **Dynamic Animations:** Bring your signs to life with built-in text animations.
* **Typography Options:** Change the font of your text using a variety of available typefaces.
* **Smart Preview & Full Screen:** Preview your animations before going live, and display your signs in an immersive full-screen mode at any time.
* **Favorites & Templates:** Instantly save your custom signs to your favorites list, or choose from a selection of pre-designed templates to save time.

## 🛠️ Tech Stack

This project was built using modern Android development practices:

* **Language:** Kotlin
* **Architecture:** MVVM (Model-View-ViewModel)
* **Navigation:** Jetpack Navigation Component
* **Dependency Injection:** Dagger Hilt
* **Local Storage:** Room Database (for saving favorite signs locally)
